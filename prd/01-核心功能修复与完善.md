## 1. 后端（API）热部署

- **后端开发命令**：`npm run dev`（实际是 `nodemon server.js`，见 backend/package.json）
- **需要挂载**：主机的 `backend/` 目录到容器 `/app`
- **需要挂载**：主机的 `node_modules` 到容器 `/app/node_modules`（推荐本地装依赖，避免权限问题）

### 后端服务 docker-compose 配置建议
```yaml
  api:
    image: node:18-alpine
    container_name: bahasa-beraja-api-dev
    working_dir: /app
    command: npm run dev
    ports:
      - "3001:3001"
    environment:
      - NODE_ENV=development
      - PORT=3001
      - DB_HOST=postgres
      - DB_PORT=5432
      - DB_NAME=bahasa_beraja
      - DB_USER=bahasa_user
      - DB_PASSWORD=bahasa_pass_2024
      - JWT_SECRET=bahasa-beraja-super-secret-jwt-key-2024-indonesian-learning
      - JWT_EXPIRES_IN=7d
      - FRONTEND_URL=http://localhost:2999
      - BCRYPT_ROUNDS=12
    volumes:
      - /绝对路径/bahasa-beraja/backend:/app
      - /绝对路径/bahasa-beraja/backend/node_modules:/app/node_modules
    networks:
      - app_network
      - bahasa_db_network
    depends_on:
      - postgres
```

## 2. 前端（React）热部署

- **前端开发命令**：`npm start`（即 `react-scripts start`，支持热更新）
- **需要挂载**：主机的项目根目录到容器 `/app`
- **需要挂载**：主机的 `node_modules` 到容器 `/app/node_modules`（推荐本地装依赖）

### 前端服务 docker-compose 配置建议
```yaml
  bahasa-beraja:
    image: node:18-alpine
    container_name: bahasa-beraja-app-dev
    working_dir: /app
    command: npm start
    ports:
      - "2999:3000"
    environment:
      - NODE_ENV=development
      - CHOKIDAR_USEPOLLING=true  # 解决热更新在docker下失效问题
      - DATABASE_URL=postgresql://bahasa_user:bahasa_pass_2024@postgres:5432/bahasa_beraja
    volumes:
      - /绝对路径/bahasa-beraja:/app
      - /绝对路径/bahasa-beraja/node_modules:/app/node_modules
    networks:
      - app_network
      - bahasa_db_network
    depends_on:
      - api
```
> 注意：端口映射为 `2999:3000`，因为开发模式下 React 默认跑在 3000 端口。
