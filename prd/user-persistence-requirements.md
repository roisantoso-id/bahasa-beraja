# 用户登录信息持久化需求文档

## 项目概述
- **项目名称**: PiMiBahasa 用户系统持久化
- **服务器地址**: http://168.231.118.179/
- **架构模式**: 前后端分离
- **数据库**: MySQL 8.0 (已配置完成)

## 1. 需求背景
当前系统使用 localStorage 存储用户信息，存在以下问题：
- 数据易丢失（清除浏览器缓存）
- 无法跨设备同步
- 不支持多用户并发
- 缺乏数据安全性
- 无法进行用户行为分析

## 2. 功能需求

### 2.1 用户认证系统
- **用户注册**: 用户名、邮箱、密码注册
- **用户登录**: 支持用户名/邮箱登录
- **密码加密**: 使用 bcrypt 加密存储
- **会话管理**: JWT Token 认证
- **登录状态**: 记住登录状态，支持自动登录

### 2.2 用户信息管理
- **基础信息**: 用户名、昵称、邮箱、头像
- **学习统计**: 学习时间、词汇掌握、测验成绩
- **VIP系统**: 会员等级、到期时间、充值记录
- **账户安全**: 密码修改、邮箱验证

### 2.3 数据迁移
- **localStorage 数据迁移**: 将现有用户数据迁移到数据库
- **数据完整性**: 确保迁移过程中数据不丢失
- **回滚机制**: 支持迁移失败时的数据回滚

## 3. 技术架构

### 3.1 前端 (React)
- **状态管理**: 使用 Context API 或 Redux
- **API 调用**: Axios 或 Fetch API
- **路由保护**: 基于 JWT 的路由守卫
- **错误处理**: 统一的错误处理机制

### 3.2 后端服务 (独立服务)
- **框架选择**: Node.js + Express 或 Fastify
- **数据库**: MySQL 8.0
- **ORM**: Sequelize 或 Prisma
- **认证**: JWT + bcrypt
- **API 文档**: Swagger/OpenAPI

### 3.3 数据库设计
- **用户表**: users (已设计完成)
- **会话表**: user_sessions
- **登录日志**: login_logs
- **操作日志**: user_activity_logs

## 4. API 接口设计

### 4.1 认证接口
```
POST /api/auth/register     # 用户注册
POST /api/auth/login        # 用户登录
POST /api/auth/logout       # 用户登出
POST /api/auth/refresh      # 刷新Token
GET  /api/auth/profile      # 获取用户信息
PUT  /api/auth/profile      # 更新用户信息
```

### 4.2 用户数据接口
```
GET  /api/user/stats        # 获取学习统计
GET  /api/user/vocabulary   # 获取词汇掌握情况
GET  /api/user/quiz-history # 获取测验历史
POST /api/user/activity     # 记录用户行为
```

### 4.3 数据迁移接口
```
POST /api/migration/import  # 导入localStorage数据
GET  /api/migration/status  # 获取迁移状态
POST /api/migration/rollback # 回滚迁移
```

## 5. 安全要求

### 5.1 数据安全
- **密码加密**: bcrypt 哈希加密
- **数据传输**: HTTPS 加密传输
- **SQL注入防护**: 使用参数化查询
- **XSS防护**: 输入验证和输出转义

### 5.2 访问控制
- **JWT Token**: 短期访问令牌
- **Refresh Token**: 长期刷新令牌
- **权限控制**: 基于角色的访问控制
- **频率限制**: API 调用频率限制

## 6. 性能要求

### 6.1 响应时间
- **登录响应**: < 500ms
- **数据查询**: < 200ms
- **数据更新**: < 300ms

### 6.2 并发处理
- **支持并发用户**: 1000+
- **数据库连接池**: 优化连接管理
- **缓存策略**: Redis 缓存热点数据

## 7. 部署架构

### 7.1 服务部署
```
前端 (React)     →  Nginx (80端口)
后端 API         →  Node.js (3001端口)
数据库 (MySQL)   →  Docker (3306端口)
缓存 (Redis)     →  Docker (6379端口)
```
