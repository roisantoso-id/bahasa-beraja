# PiMiBahasa 数据库配置

## 概述

本项目使用 MySQL 8.0 作为数据库，所有数据持久化存储在 `/home/data/pimi_bahasa_mysql` 目录下。

## 数据库架构

### 主要表结构

1. **users** - 用户表
   - 基础信息：用户名、邮箱、密码、昵称等
   - 付费相关：余额、VIP等级、充值记录等
   - 学习统计：登录次数、学习时间、连续天数等

2. **vocabulary_mastery** - 词汇掌握表
   - 用户词汇学习进度
   - 掌握等级、复习次数、正确率等

3. **quiz_history** - 测验历史表
   - 用户测验记录
   - 得分、用时、题目详情等

4. **learning_stats** - 学习统计表
   - 每日学习数据统计
   - 学习时间、词汇数、测验数等

5. **recharge_orders** - 充值订单表
   - 用户充值记录
   - 订单状态、支付方式等

6. **consumption_records** - 消费记录表
   - 用户消费记录
   - 余额变化、消费类型等

7. **vip_packages** - VIP套餐表
   - VIP套餐配置
   - 价格、权益、有效期等

8. **user_activity_logs** - 用户行为日志表
   - 用户操作记录
   - 行为分析、安全审计等
