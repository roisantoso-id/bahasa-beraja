## 功能特性

### 公开访问功能
1. **无需登录即可访问**：
   - 首页：查看学习平台概览
   - 词汇学习：浏览和学习词汇
   - 语法学习：查看语法规则
   - 商务印尼语：浏览商务内容

2. **临时数据保存**：
   - 未登录用户的学习进度保存在localStorage
   - 数据自动过期清理（7天）
   - 登录后可以同步临时数据

3. **智能登录引导**：
   - 在需要登录的功能点显示引导提示
   - 美观的UI设计，突出登录优势
   - 一键跳转到登录/注册页面

### 需要登录的功能
1. **生词本管理**：完全需要登录
2. **练习测验**：完全需要登录
3. **学习统计**：需要登录查看详细数据
4. **个人设置**：需要登录访问

## 用户体验流程

```
用户访问 → 浏览学习内容 → 点击学习功能 → 引导登录 → 登录/注册 → 继续学习
```

### 具体场景
1. **词汇学习**：
   - 未登录：可以浏览词汇、翻卡片、听发音
   - 需要登录：保存学习进度、查看个人统计

2. **首页统计**：
   - 未登录：显示临时学习数据
   - 需要登录：显示完整的学习统计

3. **功能引导**：
   - 在统计卡片下方显示登录引导
   - 突出登录后的功能优势

## 技术实现要点

### 数据管理
- **双重存储系统**：本地数据库 + 临时存储
- **状态同步**：根据登录状态自动切换数据源
- **数据清理**：定期清理过期临时数据

### 组件设计
- **条件渲染**：根据登录状态显示不同内容
- **状态管理**：使用AuthContext管理认证状态
- **响应式设计**：适配各种设备尺寸

### 性能优化
- **懒加载**：按需加载组件和数据
- **缓存策略**：合理使用localStorage缓存
- **内存管理**：及时清理无用数据
